# HereIAm · 点对点实时位置共享（Web）

HereIAm 是一个**点对点实时位置共享**网页应用。无需注册账号，基于高德地图，通过分享链接 / 分享码，即可让你和好友之间实时互看位置，还能**边说边走**（内置对讲机）。与安卓端（HereIAm-Android）完全互通。

## 🌐 在线体验

- **GitHub Pages**：https://orangeway520.github.io/HereIAm/
- **EdgeOne Pages**：https://hereiam.orangeway.top/

## ✨ 功能特性

- **分享我的位置**：一键生成专属分享链接 + 二维码，好友点开即实时查看你的位置
- **查看好友位置**：输入分享码，在地图上实时追踪好友动态
- **内置对讲机**：点对点连接后按一下麦克风即可**按键说话**，或切到**免提持续**；支持**本机静音**与「对方说话中 / 已静音」实时提示。音频走 WebRTC 点对点直传，不经服务器
- **定位键三态循环**：点击定位键即可循环切换——聚焦（居中 + 朝正北）→ 方向跟随（实时同步运动方向）→ 全部总览（一屏看全所有人）
- **地图随心旋转**：支持鼠标右键 / 双指拖拽旋转地图，最短路径平滑动画
- **用户快速切换**：顶部选择器在「自己 / 共享好友」之间一键切换
- **深色模式**：自动跟随系统，白天黑夜都舒适
- **多端互通**：网页端与安卓 App 数据、口令、语音完全打通，实时同步

## 🛠 技术栈

- 高德地图 JS API（GCJ-02 坐标系）
- Ably 实时信令（仅交换握手参数，不见位置）
- WebRTC（数据通道传位置 + 音频直传语音对讲）
- 原生 HTML / CSS / JavaScript，零框架依赖
